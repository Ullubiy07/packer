# Packer

Учебное задание на 32-битном ассемблере (x86) - простейший упаковщик (packer) секции кода с использованием XOR-шифрования.

## Требования

Для сборки необходимы:
- `nasm`
- `gcc` (с поддержкой мультиархитектуры для `-m32`)
- `make`

## Инструкция по запуску

### 1. Сборка проекта
```bash
make all
chmod +x patch.sh && ./patch.sh
make all
```
### 2. Подготовка упакованного файла
```bash
cp build/main/main ./main_packed
```
### 3. Упаковка
Шифрование секции .payload в памяти и последующая запись на диск в main_packed
```bash
./build/main/main pack
```
### 4. Распаковка и запуск
Дешифровка .payload на лету в памяти и вызов функций factor и fibb из нее
```bash
./main_packed
```
